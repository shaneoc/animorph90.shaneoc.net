Welcome to my website.

When I was around 11 years old I ran a website called Animorph90's Animorphs. The website had information on the Animorphs book series. It was online sometime around 1997. It has been a long time and so I do not remember very much, however I remember that the site had Animorphs trivia quizzes and mad libs powered by JavaScript that I had written myself.

The website used to be hosted at animorph90.hypermart.net, however I later bought the domain name ani-morphs.com and moved the site there. I met people online who wanted to assist with the site and so the design of the site changed after it was moved to ani-morphs.com. My original site had a black background, which was my preferred website background color.

I have set up this website for nostalgic reasons. I am not sure what I will put here exactly, however I like the idea of having a website that describes my original website and makes it easier to remember that it existed. Also, I am single and I am trying to find a girlfriend. Maybe there is a chance that this website will help me do that.

I have created some sub-pages:

  • Animorphs
  • Star Trek
  • The Matrix
  • Video Games

I am not sure if I will really update these sub-pages, however I felt I should add some content that attempts to reproduce the feel of the original site in some way. The original site was only on Animorphs, however I was thinking that I might treat this site as a general fan site where I describe all of the franchises that I enjoy, like Star Trek. I will think about this a bit more, maybe it makes sense to create a separate website for the other franchises.

Unfortunately, I have lost almost all of the files for the original site. I have created a page where I am planning to describe everything that I can remember about the website and the circumstances at the time.
